What the columns mean

Best at N = N drew more “Best” votes than any other count in BGG's player-count poll. Good at N = Best, or ≥50% of voters at N called N the best count. Appr = (Best + Recommended) ÷ all votes at N. Interaction is not a BGG statistic — no such data exists in their API — it is derived from each game's mechanics and categories, so treat it as a rough sort, not a fact. Point salad is a hand-maintained list.
